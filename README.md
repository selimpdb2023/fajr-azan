# ফজরের আযান — Android অ্যাপ (APK)

## APK বানানোর ধাপ (একবারই করতে হবে)
1. github.com-এ বিনামূল্যে অ্যাকাউন্ট খুলুন, নতুন একটি repository বানান (Private রাখতে পারেন)।
2. এই ফোল্ডারের সব ফাইল (লুকানো `.github` ফোল্ডার সহ) সেই repository-তে আপলোড করুন।
3. repository-র **Actions** ট্যাবে গিয়ে **Build APK** → **Run workflow** চাপুন।
4. প্রায় ৫–১০ মিনিট পরে সম্পন্ন রানে ঢুকলে নিচে **fajr-azan-apk** নামে ফাইল পাবেন। ডাউনলোড করে unzip করলে `app-debug.apk`।
5. ফোনে APK ইনস্টল করুন (অজানা উৎস থেকে ইনস্টলের অনুমতি দিতে হবে)।

## প্রথমবার চালানোর পর
- লোকেশন ও নোটিফিকেশনের অনুমতি দিন।
- ফোনের সেটিংসে অ্যাপটির ব্যাটারি অপ্টিমাইজেশন বন্ধ করুন (Unrestricted/No restrictions)।
- "টেস্ট অ্যালার্ম" চেপে দেখে নিন শব্দ ও অঙ্কের স্ক্রিন আসছে কিনা।
- অ্যাপটি অন্তত একবার খুললেই ফোনে আজকের ফজরের অ্যালার্ম সেট হয়ে যায়।
